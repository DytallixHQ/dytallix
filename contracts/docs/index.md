## What This Repo Contains

- reusable tokenomics, staking, governance, and algorithm lifecycle modules
- the shared WASM runtime and analysis tooling
- example contracts that compose the reusable modules
- test coverage for runtime, tokenomics, storage, and security helpers

## What This Repo Does Not Claim

This repository documents the reference contract surface. It does not imply that every module here is already activated in the current public network deployment path. For chain-facing API notes and current public behavior, use the Dytallix docs repository.
